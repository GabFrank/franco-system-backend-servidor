# Changelog v3.0.8

**Fecha de Release**: 2025-01-XX  
**Commit Base**: 3d6d7660674a83f58ee1880ce0576a092e573a31

## 📊 Resumen Ejecutivo

Esta actualización incluye **186 archivos Java nuevos** y múltiples mejoras significativas en el sistema. Los cambios principales se centran en la implementación completa del sistema SIFEN de facturación electrónica, sistema de notificaciones push, y mejoras sustanciales en múltiples módulos del sistema.

## 🚀 Nuevas Funcionalidades Principales

### 📄 Sistema SIFEN - Facturación Electrónica
- **Implementación completa del sistema de facturación electrónica con SIFEN**
  - **Documentos Electrónicos**: Creación automática desde facturas legales con integración completa
    - Queries GraphQL: `documentoElectronicos`, `documentoElectronico`, `documentoElectronicoPorCdc`, `documentoElectronicosPorEstado`, `documentoElectronicosPorLote`
    - Mutations: `crearDocumentoElectronicoDesdeFactura`, `consultarDocumentoElectronico`
    - Estados: PENDIENTE, EN_LOTE, APROBADO, RECHAZADO, CANCELADO
  
  - **Gestión de Lotes**: Sistema completo para agrupar y procesar documentos
    - Queries: `loteDe`, `loteDes`, `lotesPendientes`, `lotesEnProceso`
    - Mutations: `crearLote`, `vincularDocumentosALote`, `enviarLote`, `consultarLote`
    - Estados: PENDIENTE_ENVIO, EN_PROCESO, PROCESADO, PROCESADO_CON_ERRORES, ERROR_ENVIO, ERROR_RED, ERROR_PERMANENTE, RECHAZADO
  
  - **Eventos SIFEN**: Operaciones de cancelación, nominación e inutilización
    - **Cancelación**: `cancelarDocumentoElectronico(cdc, motivo)` - Cancela DEs aprobados
    - **Nominación**: `nominarReceptorDocumento(cdc, clienteId)` - Nomina receptores para DEs innominados
    - **Inutilización**: `inutilizarNumeros(...)` - Declara rangos de números como inutilizados
    - Queries para consultar eventos por documento, estado, timbrado, sucursal con filtros avanzados
  
  - **Servicios Backend**:
    - `SifenService`: Lógica core de creación, envío y consulta de documentos
    - `SifenEventoService`: Gestión de eventos (cancelación, nominación, inutilización)
    - `SifenIntegrationService`: Integración con el flujo de facturas
    - `SifenSchedulerService`: Jobs programados para procesamiento automático
    - `EventoSifenScheduler`: Scheduler para eventos automáticos
  
  - **Características adicionales**:
    - Generación de KUDE (PDF) para documentos electrónicos
    - Reimpresión mejorada de tickets de factura legal (normal y con moneda extranjera)
    - Guardado de facturas en filiales (`saveFacturaLegalToFilial`)
    - Mutations: `nominarFacturaElectronica`, `cancelarFacturaLegal`
    - Soporte para moneda extranjera con tipo de cambio
  
  - **Nuevas entidades JPA**: `DocumentoElectronico`, `LoteDE`, `EventoCancelacionDE`, `EventoNominacionDE`, `EventoInutilizacionDE`
  - **Migraciones de BD**: V71 (implementación completa), V72-V83 (mejoras y ajustes)

### 🔔 Sistema de Notificaciones Push
- **Sistema completo de notificaciones con RabbitMQ y Firebase Cloud Messaging (FCM)**
  - Notificaciones push genéricas para múltiples eventos del sistema
  - Notificaciones en ajuste de stock y transferencias
  - Servicio de plantillas de notificaciones
  - Servicio de despacho de notificaciones con RabbitMQ
  - Gestión de notificaciones por usuario con estados de envío
  - Limpieza automática de notificaciones antiguas
  - Nuevas entidades: `Notificacion`, `NotificacionUsuario`
  - Health indicators para monitoreo del servicio de notificaciones

### 📝 Sistema de Observaciones
- **Sistema de observaciones para ventas y cajas**
  - Observaciones para ventas con categorías, subcategorías y motivos
  - Observaciones para cajas con categorías, subcategorías y motivos
  - Nuevas entidades: `VentaObservacion`, `CategoriaObservacion`, `SubcategoriaObservacion`, `MotivoObservacion`
  - Nuevas entidades: `CajaObservacion`, `CajaCategoriaObservacion`, `CajaSubCategoriaObservacion`, `CajaMotivoObservacion`

### 🔄 Replicación Lógica de Datos
- **Sistema de replicación lógica entre servidor central y filiales**
  - **Gestión de Tablas**: `ReplicationTable` para configurar qué tablas replicar
  - **Logical Replication Service**: Servicio completo para setup y gestión
    - Queries: `replicationTables`, `replicationTable`, `getReplicationStatus`, `generateCentralConnectionString`, `generateBranchPublicationName`, etc.
    - Mutations: `setupReplication`, `setupBranchReplication`, `removeReplication`, `removeBranchReplication`, `toggleReplication`, `refreshSubscription`, `refreshAllSubscriptions`
    - Operaciones remotas: `toggleRemoteSubscription`, `dropRemotePublication`, `createRemotePublication`, `createRemoteSubscription`
  - **Nueva entidad**: `ReplicationTable`
  - **Migración**: V60 (create_replication_table)

### 📦 Gestión de Pedidos y Recepción
- **Mejoras en el sistema de pedidos y recepción de mercaderías**
  - **Notas de Recepción Agrupadas**: Sistema para agrupar recepciones
    - Queries: `notaRecepcionListPorUsuarioId`, `notaRecepcionAgrupadaPorId`, `notaRecepcionListPorProveedorId`
    - Queries de productos: `pedidoRecepcionProductoPorNotaRecepcionAgrupada`, `pedidoRecepcionProductoPorNotaRecepcionAgrupadaAndProducto`
    - Mutations: `saveNotaRecepcionAgrupada`, `recepcionProductoNotaRecepcionAgrupada`, `finalizarRecepcion`, `reabrirRecepcion`
    - Estados: EN_RECEPCION, CONCLUIDO, CANCELADO
  
  - **Recepción de Productos**: Tracking de recepción por pedido
    - Estados: PENDIENTE, RECIBIDO, RECIBIDO_PARCIALMENTE
    - DTOs: `PedidoRecepcionProductoDto` con totales por unidad
  
  - **Mejoras en Pedidos**:
    - Mutation: `updateNotaRecepcion`, `addPedidoItemToNotaRecepcion`, `verificarRecepcionProducto`
    - Mejoras en distribución de pedidos a sucursales
  
  - **Nuevas entidades**: `NotaRecepcionAgrupada`, `PedidoRecepcionProducto`
  - **Migraciones**: V44-V48 (creación y modificaciones)

### 🖼️ Gestión de Imágenes
- **Sistema centralizado de gestión de imágenes**
  - **Nueva entidad**: `ImagenMaster` con soporte para múltiples tipos de referencia
  - **Queries GraphQL**:
    - `imagenMaster`, `imagenesMaster`, `imagenesByEntityTypeAndId`, `imagenPrincipal`
    - `imagenAsBase64`, `imagenesAsBase64`
    - `getImageWithBackwardCompatibility` (compatibilidad con sistema anterior)
  - **Mutations**:
    - `saveImagenMaster`, `deleteImagenMaster`, `setPrincipalImagen`, `getOrSaveDefaultImage`
    - Migración: `migrateSingleImage`, `migrateAllImagesForType`
  - **Controladores REST**: `ImageMigratorController`, `ImagenMasterController`
  - **Migración**: V61 (create_imagen_master_table)

### 📊 Control de Inventario y Productos
- **Mejoras en control de inventario y gestión de productos**
  - Lista de productos vencidos con filtros por sectores y zonas
  - Filtro de stock positivo en búsqueda de productos
  - Filtro de productos vencidos en inventarios
  - Filtro por inventario anterior
  - Mejoras en reporte de productos
  - Ajuste de costo y stock en reportes
  - Prevención de productos duplicados en inventario
  - Mejoras en cálculo de venta media en lucro por producto
