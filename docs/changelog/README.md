# Changelog

Este directorio contiene el historial de cambios del proyecto organizado por versión.

## Estructura

Cada versión tiene su propio archivo con el formato `v{VERSION}.md` (ej: `v3.0.8.md`).

## Versiones Disponibles

- [v3.0.8](v3.0.8.md) - Actualización desde commit 3d6d766 (Sistema SIFEN, Notificaciones Push, Gestión de Pagos)

## Formato

Cada archivo de changelog sigue el siguiente formato:

- **Nuevas Funcionalidades**: Funcionalidades agregadas
- **Mejoras y Ajustes**: Mejoras en funcionalidades existentes
- **Correcciones**: Bugs corregidos
- **Documentación**: Cambios en documentación
- **Integraciones**: Nuevas integraciones o mejoras

## Convenciones

- Usar emojis para categorizar los cambios (🚀, 🔧, 🐛, 📚, etc.)
- Incluir referencias a commits cuando sea relevante
- Mencionar migraciones de base de datos y cambios importantes
- Indicar breaking changes si los hay
